# Particle Orbit · 粒子环绕生成器

Blender 5.1 插件。一键生成发光粒子环，粒子按时间线绕模型或 3D 游标旋转，并沿环轴起伏。每个粒子的位置与大小由随机种子决定。

## 安装与使用

1. 下载 [particle_orbit.py](particle_orbit.py)。在 Blender 打开 **编辑 → 偏好设置 → 插件**，从右上角菜单选 **从磁盘安装**，选择这个文件，再启用 **Particle Orbit**。
2. 在物体模式选中一个模型，按 **N** 打开 3D 视图侧栏，切到 **粒子环绕**。开启 **跟随活动对象** 和 **按模型尺寸设置半径** 时，环以模型包围盒中心为起点并随模型变换。关闭跟随或取消对象选择时，环以 3D 游标为中心。
3. 点击 **生成粒子环绕**，切到材质预览，播放或拖动时间线。生成后的环是一个独立物体。可在其几何节点修改器中调整粒子数量、半径、环带宽度、起伏、大小、转速、随机种子和材质。默认发光颜色和强度可在着色器编辑器里继续修改。

### 无缝循环

起始帧默认取生成时的场景起始帧。默认每 120 帧转一圈。若从第 1 帧导出一个完整循环，渲染 **1–120 帧**，第 121 帧会回到第 1 帧的位置。圈数为负值时反转方向，零值时静止。

粒子用几何节点实例生成，保存的 `.blend` 内包含节点和材质。禁用插件后，已生成的环仍可播放和渲染。默认材质会自发光。如需镜头中的光晕，可在合成器添加 **眩光（Glare）→ 辉光（Fog Glow）**。
